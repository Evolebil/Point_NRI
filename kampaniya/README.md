# Кампания «Аномалии планов»

Документы кампании лежат в хранилище Obsidian владельца: `~/Documents/Учёба/Obsidian_Vault/Компейн - Аномалии планов/`. Здесь их нет — здесь только то, что нужно для карт и для движка.

## karty/ — карты мира 1208 года
Скрипты на Python рисуют карты в Obsidian (`Мир/География/Карты/`), описания слоёв — `Мир/География/Карта мира.md`.

| Файл | Что делает |
|---|---|
| `realms.py`, `states.py` | государства 1208 года: кому принадлежит каждая провинция; карта государств с границами |
| `cities_data.py`, `cities.py` | города около 1200 года (Buringh + Чандлер, с исправлением координат); карта городов |
| `itinere.py`, `routing.py`, `routes_data.py`, `build_routes.py`, `roads.py` | римские дороги Itiner-e, прокладка путей по дорогам, рекам и морю; карта путей |
| `biomes.py`, `races.py`, `dragons.py` | биомы, расы по биомам, логова драконов; карта рас |
| `langs.py` | людские наречия |
| `resources.py` | ресурсы и места добычи |
| `act1.py` | карта местности Акта I (Париж — Каркассон) |
| `interactive.py`, `interactive_template.html` | интерактивная карта (Leaflet); шаблон сам по себе пустой — готовая карта собирается в `Карты/Интерактивная карта/index.html` |
| `geodata/` | скачанные данные (~86 МБ): Natural Earth (общественное достояние), Itiner-e (CC BY 4.0), Buringh (CC0), Чандлер (CC BY 4.0), `routes.json` — проложенные пути |

Порядок пересборки: `python3 build_routes.py` (если менялись пути), затем нужные карты, затем `python3 interactive.py "<папка интерактивной карты>"` (`--html` — только страница, без картинок слоёв).

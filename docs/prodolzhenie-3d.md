## 2. Карта кода режима кубов (только нужное)

- `src/engine/vox.h` — всё про кубы: `MAT` (материалы: хиты, КД, твёрдость, прозрачность), `VoxWorld` (`at`, `set`, `dmg`,
  `edits`, `changes`), `damageVox`, `voxColumn`/`voxFromWorld` (карта → кубы, те же правила, что `r3Column` в клиенте),
  `vxResync`, `vxStand`/`vxStandEx`/`vxBodyFree`, `vxStep`, `vxStepCost`, `vxPathTo`, `vxLos`, `vxDig`, `vxAfterBreak`,
  `g_voxMode`.
- `src/engine/world.h` — `Fighter::z`, `zCol`; `World::vx` (nullptr — прежний бой); `VZ0 = 2`; `fL()` (ярус: прежний 0/1,
  в кубах — z); ветки `if (w.vx)` в `zAt`, `nodeZ`, `zF`, `maxAltAt`, `nodeOK`, `fpAt`, `stepOK`, `stepCostL`, `losZ`,
  `pathTo`, `nudge`, `moveToCell`; `g_vxTz` (высота цели хода игрока).
- `src/engine/actions.h` — `vxFixAll` (перед каждым кадром: на опору / падение), вызовы `vxResync` в дверях, барьерах,
  разрушении объектов и настилов.
- `src/engine/fight.h` — построение мира из кубов в начале боя, `vxFixAll` в `emitFrame`.
- `src/engine/human_turn.h` — `move` с `z`, `hitobj` с `z` (удар по блоку); без пути под мышью и кнопок высоты в кубах.
- `src/engine/chase.h` `fighterJson` — `"z"` в кадре; `custom_map.h` `mapToJson` — `"vox":1`.
- `src/apps/arena_play.cc` — `"vox":1` в `start` → `g_voxMode`, соперник — правило-бот; комнаты — `g_voxMode = false`.
- Клиент: `web/js/55_render3d.js` (`R3`: кубы, `syncVox`, `ENG2VM`, `cellAt` с `z`/`oz`), `52_turn.js` (щелчки),
  `51_room.js` (`msg.vox` при `?3d=1`), `40_maps.js` (редактор 5 фт, кисть дерева).
- Проверки: `tests/audit/13_T212_vysota_5ft.inc` — T212 (5 фт), T216 (деревья генератора), T217 (`VoxWorld`), T218 (режим
  кубов); `tests/test_render3d.mjs` (17).

## 3. Как проверять (каждый этап)

```
make
sh tests/run_tests.sh                       # 233/235: падают только известные T22, T126
python3 -m unittest tests/test_server_integration.py
python3 tests/test_play.py
node tests/test_render3d.mjs
```
- **Прежний бой не ломать**: сверить хеши `./build/arena 0 600 6 42 | md5sum` и `DND_NETP=off ...` до/после правки
  (эталон — сборка прошлого коммита в отдельной `git worktree` + незакоммиченные `char_spec.h`/`gen_spec.h`, см. ниже).
  Все ветки режима кубов — под `if (w.vx)`.
- Браузер: `python3 web/play_server.py 8770` (или `.claude/launch.json` «play»), `http://localhost:8770/?3d=1`, быстрый
  бой; макет — `/demo3d`. После правок C++ — `make` и перезапуск сервера.
- Живая ссылка (`relay/worker_url.txt`) и телефон — **ещё не проверялись** (туннель не запускали: сервер отдаёт рабочую
  папку, сайт будет на ветке `3d`; спросить владельца).

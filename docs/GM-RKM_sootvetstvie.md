## 2. Формат боевой карты

| Приложение А (табл. А.1) | В коде (`custom_map.h`, `meToJson`) | Замечание |
|---|---|---|
| `format`, `version: 2`, `id` (UUID) | нет; карта в списке — по имени (`MAPS[имя]`) | Добавить при версии 2 (ТЗ п. 4.5.1) |
| `w`, `h` | `aw`, `ah` | Существующие имена (прил. А, вступление) |
| `relief` (R01…R07), `objects` (O01…O05), `hazards` (H01…H07) — массивы чисел | 13 слоёв строками base36 по рядам: `wall, pit, water, diff, climb, dark, height, tree, haz, ladder, deck, door, strong` | Клетка может иметь сразу несколько слоёв (стена + настил, опасное + тьма); один код на группу этого не выражает — В-02 |
| `height` 0–20 уровней | `height`, `deck`, `tree` — уровни по 5 фт, 0–35 (`"hz":5`; старые карты ×2) | Д-27 (0–20) меньше, чем умеет движок — В-03 |
| `starts`: по 1–16 клеток на сторону (Д-06) | `starts: [[x,y],[x,y]]` — одна клетка на сторону (движок ставит бойца в неё) | В-06 |
| `assets`, `embedded`, `source`, `updatedAt` | нет | Добавятся на Ш-04 и Ш-11 |
| — | `vx` — слой кубов (пещеры, дома генератора для 3D), `theme` (тип местности 0/1) | Сохраняется как есть |

Материалы палитры (табл. 7) совпадают с кодом по составу (`TOOLS`, `TOOL_GROUPS`): «Укрытие» = слой `climb`, «Крепкая стена» = `strong` (+`wall`), опасное H01…H06 = `haz` 1…6, H07 «Тьма» = отдельный слой `dark`. В коде у дерева есть высота 10–40 фт (`meTreeH`), в ТЗ её нет — сохраняется.

## 4. Серверный интерфейс

Сейчас один вход `POST /api` с полем `cmd` (`web/play_server.py`, `do_POST`), плюс `GET` для страницы, портретов, библиотек 3D и моделей.
REST-путей `/api/assets`, `/api/worlds/...` (табл. 23) нет. Сервер — Python на компьютере хозяина; Cloudflare Worker (`relay/worker.js`)
только пересылает запросы через туннель (WebSocket) и с 2026-11-19 раздаёт библиотеки 3D и модели сам (статические файлы).
Своего хранилища (R2, KV, D1) у Worker нет — В-01.

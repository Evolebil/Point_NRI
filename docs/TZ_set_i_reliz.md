# ТЗ: сетевая игра и релиз (разбор с владельцем, 2026-11-03)

Зачем: проверять игру на игроках из сообщества D&D; удобно для всех.

## Требования владельца

**Сетевая игра.** Два игрока запускают игру у себя и играют друг против друга.

**Релиз:**
1. Исполняемый файл (Windows и Linux).
2. Исходный код — в гит (git push).
3. Релизный код — отдельная папка с хорошей архитектурой.
4. Архив этого кода.
5. Первый релиз для Windows и Linux.

## Решения

| Вопрос | Решение |
|---|---|
| Когда | Код сетевой игры и сборки — до обучения (после механик); первый релиз — после обучения, с обученными сетями. |
| Как находят друг друга | По коду комнаты через интернет: один создаёт комнату и передаёт код. Посредник — маленький сервер, только пересылает сообщения; бой считает программа одного из игроков. |
| Что входит в программу | Сама игра (конструктор, бой, редактор карт, выбор мира) и правила к ней. Обучения сетей нет. |
| Правила в программе | Отдельная книга правил для игроков: коротко и понятно (сборка босса, бой, местность, мир, сетевая игра), без ссылок на проверки, цен атомов и калибровки. `pravila-v21.md` остаётся для разработки. |
| Гит | GitHub, аккаунт Evolebil, репозиторий **DND_PRO**, открытый; релизы (Windows, Linux) — на странице релизов GitHub. |
| Что в гит | Исходники, страницы, правила, веса сетей (около 2 МБ). Не класть: `models/` (языковая модель 5,3 ГБ), `net_runs/`, `builder_runs/`, собранные программы, `Sushnost/` (инструмент извлечения атомов — игрокам не нужен). |
| Хостинг посредника | Cloudflare Workers (бесплатно, без карты; владелец регистрируется сам). Проверить скорость в России; запасные — Render, дешёвый VPS. Код посредника — переносимый. |

# ТЗ: бои нескольких команд (разбор с владельцем, 2026-11-03)

Зачем: сейчас только дуэль 1×1 и босс с миньонами — проверка на игроках будет неполной.

| Вопрос | Решение |
|---|---|
| Кто в команде | Любая смесь героев (из конструктора) и боссов (с миньонами); каждым управляет игрок (по сети) или бот/сеть. |
| Сколько команд | Без ограничения (только технический предохранитель, как у призыва); размер команды — тоже. |
| Победа | Последняя команда, в которой кто-то жив (сбежавший выбывает). Если бой затянулся — победа по очкам (как считать очки — уточняется). |
| Очки (если затянулся) | Предел раундов выбирает игрок (10/20/50/без предела; технический — 500). Очки команды = доля оставшихся хитов команды + 1 за каждого убитого врага; равные очки — ничья. |
| Сделано (2026-11-03) | Движок `fightRoster` (состав, команды, расстановка группами, очки), `fight(A,B)` — тот же бой бит в бит (T126). Комнаты на сервере (`room_*`), лобби и бой в браузере, ход своих приспешников. |

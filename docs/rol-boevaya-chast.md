# Роль: боевая часть Point_NRI

Point_NRI — новое имя DND_PRO (папка пока называется `DND_PRO`). Этот файл — для того, кто работает с **боем**: движок, атомы и их цены, калибровка, сети (боец и Сборщик), тесты, игра в браузере.

## Читать в первую очередь
- `README.md` — папки, команды, правила разработки (эталон `golden`, детерминизм, обнуление обучения при смене правил сборки).
- `docs/pravila-v21.md` — правила боя и таблица цен; `docs/katalog-atomov.md`; `docs/TZ_backlog.md` — список работ; `docs/istoriya-razrabotki.md` — журнал.
- Код: `src/engine/` (начать с `engine.h`), `src/ai/`, `src/apps/`; проверки — `tests/`; инструменты — `tools/`, прогоны — `scripts/`, потолки — `config/limity.json`.
- Итоги прогонов: `results/` (калибровка, лестницы, тесты, профили).
- `Sushnost/result/`, `Sushnost/result_gaps/`, `Sushnost/summary_gaps.md` — выгрузка механик бестиария и найденные пробелы: источник новых атомов.

## Не читать и не трогать
| Путь | Почему |
|---|---|
| `kampaniya/` | кампания и карты мира: к бою не относится. Противники кампании пока не собираются («рано собирать», владелец) |
| `models/Qwen3.5-9B-Q4_K_M.gguf` | 5 ГБ, двоичная языковая модель; её запускает только конвейер `Sushnost` через llama.cpp — читать файл незачем |
| `Sushnost/venv/` | 157 МБ: окружение Python конвейера, чужие библиотеки |
| `Sushnost/*.log` | журналы прогонов модели — шум |
| `relay/node_modules/` | 222 МБ библиотек Node для туннеля Cloudflare |
| `relay/host_key.txt` | **секрет** туннеля: не читать, не печатать, не коммитить |
| `state/` | игроки сервера (`players.json` — имена людей), адрес туннеля, журнал сервера: личные и рабочие данные |
| `build/` | собранные программы: их запускают (`make`), а не читают |
| `runs/net/*.bin` | веса обучения (346 МБ): двоичные; читать только журналы и отчёты рядом |

## Общее с исследованием и социалкой
Атомы и цены (`src/engine/atoms.h`, `core.h`), персонаж (`char_spec.h`), конструктор (`web/js/`) — общие. Небоевые навыки и инструменты сейчас стоят временную цену (атом 94, «до исследования и социалки»): их меняет вторая роль — по договорённости. Любая смена правил сборки обнуляет обучение Сборщиков и ботов (README) — согласовывать заранее.

## Запрет на уровне инструментов (по желанию)
Файл `.claudeignore` Claude Code не читает. Надёжный способ — запрет в `.claude/settings.local.json` проекта:

```json
{
  "permissions": {
    "deny": [
      "Read(./kampaniya/**)", "Read(./models/*.gguf)", "Read(./Sushnost/venv/**)", "Read(./Sushnost/*.log)",
      "Read(./relay/node_modules/**)", "Read(./relay/host_key.txt)", "Read(./state/**)",
      "Edit(./kampaniya/**)", "Edit(./relay/host_key.txt)", "Edit(./state/**)"
    ]
  }
}
```
